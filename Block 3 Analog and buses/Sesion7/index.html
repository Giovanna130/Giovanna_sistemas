    Sesion 7 — ADC

    Goal: Program the Raspberry Pi to read and measure the signals from a light sensor, a temperature sensor, a microphone, and a potentiometer, using the analog-to-digital converter (ADC) to obtain their values.

    Prediction: The Raspberry Pi is expected to record different numerical values ​​according to variations in light, temperature, sound, and potentiometer position, allowing observation of how each sensor responds to different stimuli.

    Temperature sensor

    Set Up

    We connected the temperature sensor to the Raspberry Pi, first its power and ground terminals to the corresponding pins on the board, while the signal output was connected to an analog ADC input so that the Raspberry Pi could read the voltage variations.

    What I did

    During the experiment, we connected the temperature sensor to the Raspberry Pi using pin GP26, corresponding to channel ADC0, to read the analog signal it generated. We then programmed the board to initialize the analog-to-digital converter (ADC), select the input channel, and obtain the sensor readings. The program converted the digital values, ranging from 0 to 4095, to a voltage between 0 and 3.3 V and subsequently calculated a temperature from that voltage. Finally, the digital readings were displayed on the computer every 500 milliseconds, allowing us to observe how the signals recorded by the sensor changed.

    Code

    #include <stdio.h>
#include "pico/stdlib.h"
#include "hardware/adc.h"

// Configure the ADC channel to use
#define ADC_INPUT 0 // channel 0
#define ADC      3.3f      

int main() {
    stdio_init_all();
    adc_init();
    // Configure the corresponding GPIO pin as an ADC input
    adc_gpio_init(26); // GPIO26 usually maps to ADC0 on the Pico 2
    // Select the channel
    adc_select_input(ADC_INPUT);

    // Optional: adjust the clock divider if you need to limit Fs
    // adc_set_clkdiv(div);

    while (true) {
        uint16_t adc = adc_read(); // 12 bits aligned to 0..4095
        float v = (adc * ADC) / 4095.0f;
        float temp = (v * 1.0f) / 0.01f;
        printf("%u\n", adc);
        sleep_ms(500);
    }
}

    Light Sensor

    Set Up

    To perform the light sensor exercise, we connected the sensor to the Raspberry Pi, connecting its power supply to 3.3 V, its ground to the GND pin, and its analog output to the GP26 (ADC0) pin.

    What I did

Then, we used code to initialize the analog-to-digital converter (ADC), select the ADC0 channel corresponding to pin GP26, and read the sensor signals.     Potentiometer

    Set Up

    We connect its three terminals to the Raspberry Pi, the first terminal to 3.3 V, the second to GND and the central terminal (output) to pin GP26 (ADC0).

    What I did

    During the experiment, we connected the potentiometer to the Raspberry Pi and ran the code to read the signals using the ADC. As we turned the knob, we observed how the recorded numerical values ​​and the percentage displayed on the computer changed every 500 milliseconds, relating the potentiometer's movement to the voltage variations.

    Code

    #include <stdio.h>
#include "pico/stdlib.h"
#include "hardware/adc.h"

// Configure the ADC channel to use
#define ADC_INPUT 0 // channel 0
#define ADC 3.3f  

int main() {
    stdio_init_all();
    adc_init();
    // Configure the corresponding GPIO pin as an ADC input
    adc_gpio_init(26); // GPIO26 usually maps to ADC0 on the Pico 2
    // Select the channel
    adc_select_input(ADC_INPUT);

    while (true) {
        uint16_t adc = adc_read(); // 12 bits aligned to 0..4095
        float porcentaje = ((adc - 1.0f) * 180.0f) / (3374.0f - 1.0f);
        //float luz = ( ) ;
        printf("%u\n", adc);
        printf("%.1f\n", porcentaje);
        sleep_ms(500);
    }
}

    Microphone

    Set Up

    To connect the microphone to the Raspberry Pi Pico 2W, first connect the microphone's VCC pin to 3.3V and its GND pin to ground (GND) on the board. Then, connect the microphone's analog output (OUT) to pin GP26 (ADC0) so the Raspberry Pi can read the voltage variations produced by the sound.

    Code

    #include <stdio.h>
#include "pico/stdlib.h"
#include "hardware/adc.h"

// Configure the ADC channel to use
#define ADC_INPUT 0 // channel 0
#define ADC 3.3f
#define N 100       // muestras por segmento

int main() {
    stdio_init_all();
    adc_init();
    adc_gpio_init(26); // GPIO26 -> ADC0
    adc_select_input(ADC_INPUT);

    while (true) {
        uint16_t minimo = 4095;
        uint16_t maximo = 0;

        // Tomar un segmento de N muestras
        for (int i = 0; i < N; i++) {
            uint16_t adc = adc_read(); // 12 bits 0..4095
            if (adc < minimo) minimo = adc;
            if (adc > maximo) maximo = adc;
            sleep_us(100);
        }

        uint16_t pp = maximo - minimo; // amplitud del sonido
        float porcentaje = (pp * 100.0f) / 3374.0f;

        printf("%u\n", pp);
        printf("%.1f\n", porcentaje);
        sleep_ms(500);
    }
}
